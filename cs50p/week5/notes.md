### My explanations (in my own words)

1. What does assert do, and what happens if the condition is false?

It checks if a condition or statement evaluates to True. The program immediately stops and raises an `AssertionError`, indicating that something in the code is not working as expected.

2. Why are tests placed in a separate file instead of the same file as the code?

It keeps your main application code lightweight and free of testing clutter.

3. What does pytest do when it runs?

It automatically searches your directories for files starting with `test_` or ending with `_test`. • It captures the `assert` statements, checks which tests passed or failed, and displays a clean summary in the terminal.
